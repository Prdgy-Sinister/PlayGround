## 🎧 Music Empire — Music Industry Tycoon

A complete, browser-based label management sim. Start with $150K, a bedroom studio and no artists. Scout talent, cut records, fight for chart positions, run campaigns and tours, buy out rivals and build the biggest label in the world.

### Play

```bash
python3 -m http.server 3002
```

Open <http://localhost:3002>. No build step, accounts or dependencies — the whole game is vanilla HTML, CSS and JavaScript, and it saves automatically to `localStorage`.

### What's inside

- **Roster & talent** — scouting reports, contract negotiation, morale, loyalty, royalties, renewals and rival poaching.
- **Studio & production** — producers, songwriters, features, studios, equipment, budgets and creative focus all shape each record.
- **Releases & charts** — singles, EPs and albums, release timing, marketing spend, weekly streaming charts, chart peaks and catalog decay.
- **Business** — campaigns, tours, distribution deals, staff, facilities, loans, P&L reports, awards and tier progression.
- **Living market** — six AI labels release music, sign free agents, climb the charts and respond to trends.
- **Decisions** — random events, contract disputes, studio failures, label acquisitions and a game-over/restart loop.
- **Responsive UI** — full desktop sidebar layout and a mobile bottom-nav experience with sheet-style modals.

Progress saves under the `music-empire-save-v1` key. Use **Company → Start a new label** to begin a fresh run.
